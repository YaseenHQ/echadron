# Shared Echadron telemetry

Shared telemetry infrastructure used by Echadron. The package scope and
wire-compatible Kimi endpoint names remain unchanged so existing integrations
continue to work during the host-product migration.

Part of the [Kimi Code](https://github.com/MoonshotAI/kimi-code) monorepo.

See the main repository for documentation, issues, and contribution guidelines.
